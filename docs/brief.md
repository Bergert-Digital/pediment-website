# Pediment Website — brief

Written by `/pediment:start`. This is the durable record of what the site is for.
It is read by humans and by agents working in this repo; **nothing reads this file programmatically**, so editing it changes documentation, not behaviour.

## What they do

Presents the Pediment project: a WordPress plugin that ships a shared site engine (a design layer of named block styles, templates, patterns, design tokens, forms, seeding and MCP tools for AI agents) paired with lean standalone client themes.

## Who for

Agencies and developers evaluating Pediment for client work, and contributors orienting themselves in the project.

## Tone

Technical but plain-spoken. Confident, concrete, no marketing fluff.
